# 赣南科技学院毕业论文 LaTeX 模板

完全符合学校官方格式要求的毕业论文LaTeX模板。

## 📦 文件清单

```
├── main.tex                 # 主论文文档（核心文件）
├── 小论文模板.tex            # 小论文模板
├── compile.bat              # 论文编译脚本
├── compile_小论文.bat        # 小论文编译脚本
├── setup.bat                # 初始化脚本
├── 快速开始.txt              # 新手入门指南
├── 格式检查清单.txt          # 答辩前检查清单
├── figures/                 # 图片文件夹
└── README.md                # 本文件
```

## 🚀 三步开始

### 1. 安装LaTeX环境
下载并安装 [TeX Live](https://mirrors.tuna.tsinghua.edu.cn/CTAN/systems/texlive/Images/texlive.iso)

### 2. 修改论文信息
打开`main.tex`，找到第130-147行，修改你的信息：
```latex
\newcommand{\thesistitle}{基于Spring Boot的图书管理系统的设计与实现}
\newcommand{\thesisauthor}{张三}
\newcommand{\studentid}{20210001}
...
```

**重要：**同时修改第172行的页眉信息：
```latex
\fancyhead[CE]{\songti\zihao{5}张三：基于Spring Boot的图书管理系统的设计与实现}
```

### 3. 编译论文
双击运行`compile.bat`即可生成PDF

## 📝 格式要点

### 页码编排
- **摘要到目录**：罗马数字 I、II、III...（有页眉）
- **正文到致谢**：阿拉伯数字 1、2、3...（从1重新开始）
- **小论文**：阿拉伯数字 1、2、3...（无页眉，从1开始）

### 字体字号
| 内容 | 字体字号 | 行距 | 其他 |
|------|---------|------|------|
| 论文题目（中） | 小一号黑体 | 单倍 | 居中 |
| 摘要/ABSTRACT | 三号黑体/Times粗 | 单倍 | 居中，空两格 |
| 章标题 | 小三号黑体 | - | 居中，段前后各1行 |
| 节标题 | 四号宋体加粗 | - | 顶格，段前后各0.5行 |
| 小节标题 | 四号楷体加粗 | - | 顶格，段前后各0.5行 |
| 正文 | 小四号宋体 | 20磅 | 首行缩进2字符 |
| 图表标题 | 五号黑体 | - | 居中 |
| 目录内容 | 四号 | 1.5倍 | 一级黑体、二级宋体、三级楷体 |

### 编号格式
- **图**：图1-1、图1-2...（M-N，M章号N序号）
- **表**：表1-1、表1-2...
- **公式**：(1-1)、(1-2)...

### 摘要格式
- **中文**：内容首行缩进2字符，关键词3-5个，最后无标点
- **英文**：内容首行缩进4个半角空格

## 📐 插入图表公式

### 图片
```latex
\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.6\textwidth]{figures/图片.png}
    \caption{图片说明}
    \label{fig:标签}
\end{figure}
```
引用：`如图\ref{fig:标签}所示`

### 表格
```latex
\begin{table}[htbp]
    \centering
    \caption{表格标题}
    \label{tab:标签}
    \begin{tabular}{ccc}
        \toprule
        列1 & 列2 & 列3 \\
        \midrule
        数据 & 数据 & 数据 \\
        \bottomrule
    \end{tabular}
\end{table}
```

### 公式
```latex
\begin{equation}
    E = mc^2
    \label{eq:标签}
\end{equation}
```
引用：`如式(\ref{eq:标签})所示`

## ⚠️ 重要提醒

1. **必须使用XeLaTeX编译器**（不是pdfLaTeX）
2. **编译2-3次**才能生成正确的目录和引用
3. **修改第172行页眉**为你的实际姓名和题目
4. **参考文献至少15篇**，近5年为主，需有外文文献
5. **图表标题是五号黑体**（不是小五）
6. **关键词最后无标点符号**

## 🔍 常见问题

**Q: 目录显示不正确？**  
A: 编译2-3次，第一次生成信息，后续才正确显示。

**Q: 图片不显示？**  
A: 确保图片在`figures/`文件夹中，路径正确。

**Q: 页眉显示"学生姓名：论文题目"？**  
A: 修改main.tex第172行为你的实际信息。

**Q: 编译失败提示找不到字体？**  
A: Windows系统通常已有中文字体，如报错请安装宋体、黑体等。

## 📚 参考文献要求

**格式示例：**
```
[1] 何海浪. 机器人铣削加工轨迹规划与颤振稳定性研究[J]. 计算机应用, 2020, 7(3): 167-173, 186.
[2] 严蔚敏. 数据结构（第四版）[M]. 北京: 清华大学出版社, 2019: 234-236.
```

**要求：**
- 数量不少于15篇
- 一般为近5年文献
- 应有外文参考文献
- 作者只写到第三位，余者写"等"或"et al"
- 按正文引用顺序排列
